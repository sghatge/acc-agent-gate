How a tool call travels

Adobe’s CX Enterprise agentic tools list Campaign Classic capabilities that include query execution, workflow control and SOAP/JS execution [1]. The gate is an MCP server the agent talks to instead. Approvals are not a tool the agent can call.

Policy lab

Loosen a rule and watch the same session play out

Every change re-runs all 28 agent calls through the gate in your browser. Simulated approvers sign whatever reaches them, except the production reminder they reject for a business reason. That is the point: humans alone miss what policy catches.
